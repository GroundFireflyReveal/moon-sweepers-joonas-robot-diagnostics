## 🛠️ Troubleshooting / Fix Workflow

1. Confirm every player uses Moon Sweepers 1.0.4 or later; the earlier off-screen pause was addressed by the developer.
2. Open the improved Moon map and inspect the robot’s current activity and sector.
3. Look at the robot information panel, including the bin/full indicator.
4. Check for a reachable Capsule Catcher and whether it has capacity; the patch lists a 100 kg catcher capacity.
5. Watch one hex and one capsule delivery rather than judging progress across the entire base.
6. If an individual robot still stalls, record the sector, world size, player count and version before reporting it.

## ❓ FAQ

**Does a J.O.O.N.A.S. need a nearby player?**  
Not in 1.0.4: unattended cleaning was added to the game.

**Should robots always return to the dock?**  
No. In 1.0.4 they send capsules toward the nearest catcher while moving to the next sector.

**Does the bundled executable apply these fixes automatically?**  
No. The included executable is a renamed copy of WinGUp configured for Notepad++ updates; it is not a Moon Sweepers fixing tool. The game-specific troubleshooting steps are provided in this README.
